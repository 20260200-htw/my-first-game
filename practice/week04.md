# 4주차 실습 정리

## 오늘 한 것
- 원형 / AABB / OBB Bounding Box 시각화
- 세 방식의 충돌 판정 차이 관찰

## 관찰 내용

### 원형 vs AABB
- 원형 바운딩 박스의 경우, 중심점으로부터 전방위로 직선거리 r만큼의 지점들을 포함하기 때문에
- 모서리 부분에서 AABB에 비해 더 좁은 충돌 감지 범위를 가진다.

- AABB의 경우, 화면축 X,Y를 기준으로 만들어진 바운딩 박스이기 때문에
- 모서리 부분에서 원형 바운딩 박스에 비해 더 넓은 충돌 감지 범위를 가진다.

- 오브젝트의 지름이 2r일 때:

- 원형 바운딩 박스의 반지름이 r일 때는 오브젝트의 모서리 부분에 빈 공간이 있지만,
- AABB는 지름이 2r일 때는 빈 공간 없이 오브젝트의 모서리 부분을 모두 채울 수 있기 때문이다.
- (AABB는 사각형 바운딩 박스이기 때문에 오브젝트의 지름이 r이라면 모서리 부분까지 모두 채울 수 있다.)

### AABB vs OBB
- AABB는 오브젝트가 회전할 때 같이 회전하지 않고, 오브젝트의 모서리 꼭짓점에 따라 크기가 변하지만,
- OBB는 오브젝트의 회전에 따라 충돌 감지 범위가 같이 회전하며, AABB와는 달리 범위의 크기가 변하지 않는다.

- AABB는 오브젝트가 회전할 때 계속해서 크기가 변하기 때문에 움직이는 오브젝트의 바운딩 박스로는 어울리지 않지만,
- OBB는 오브젝트가 회전할 때 같이 회전할 뿐 크기가 변하지는 않기 때문에 움직이는 오브젝트의 바운딩 박스로 적합하다.


## AI와의 대화에서 배운 것
- AABB와 OBB의 결정적인 차이는 오브젝트의 상태에 따라 변하는 값의 차이라는 것.

- AABB는 오브젝트가 회전할 때 크기'만' 계속해서 변하지만, OBB는 오브젝트가 회전할 때 크기는 변하지 않고 같이 회전한다.
- 하지만 오브젝트가 커졌을 때는 OBB의 크기도 오브젝트와 똑같이 커진다.

## 내 게임에 적용한다면
- 정지된 오브젝트(예: 건물이나 상자 등)에는 AABB를 사용하고,
- 움직이는 오브젝트(예: 플레이어블, 보행하는 NPC 등)에는 OBB를 사용할 것 같다.
- AI의 보충: 정밀한 동작이 필요없는 오브젝트에는 원형 바운딩 박스를 사용하는 것이 유리하다.
