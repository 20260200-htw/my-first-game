# 7주차 실습 기록

## 중간 프로젝트 개발 과정 총 정리

### 게임 내적 과정

- 게임 시스템 추가 / 패링, 체력, 보스, 시나리오 등
- 게임 플레이 방식 변경 / 기존의 방식: 피하는 만큼 점수 획득 -> 변경한 방식: 패링으로 공격을 튕겨내고 보스를 격파
- 보스의 페이즈 추가 및 페이즈별 패턴 추가 / 1~3페이즈
- 스프라이트 및 효과음, 배경음 추가 / 온라인 무료 에셋을 사용, 폴더에 출처 텍스트 파일에 출처 명시
- 스프라이트 제작 / 일반 투사체와 특수 투사체 패링 이펙트 스프라이트를 직접 제작하여 사용
- 플레이 테스트 / 직접 플레이하고, 퍼펙트 클리어(100점)의 난이도를 테스트, 게임 플레이를 녹화
- 난이도 조절 / 플레이어의 체력을 50 -> 100으로 상향, 게임의 난이도를 하향

### 게임 외적 과정

- Claude AI를 사용하여 게임을 개발
- 사용량을 모두 쓰거나 부족한 부분이 있을 경우, 다른 AI(ChatGPT 등)를 사용하여 보충
- 스프라이트 제작에는 Aseprite를 사용, 스프라이트 시트 제작은 학습 자료를 사용
- 친구에게 플레이 테스트를 요청하여 다른 사람이 느끼는 난이도를 파악 (어렵다고 하였음)
- 게임 플레이와 게임 내 요소를 녹화하여 중간 프로젝트 파일에 첨부
- 제출 이후에도 부족한 점을 보충하여 재제출
