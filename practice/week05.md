# 5주차 실습 기록

## 선택한 템플릿 및 주제
- 템플릿: dodger
- 주제: 패링 기능을 추가한 피하기 및 액션 게임 "패링 용사" (임시 제목)

## 사용한 AI 프롬프트 (요약)
1. 코드 구조 설명 요청
   - dodger 템플릿의 전체 코드 구조 설명을 요청함
2. 기획서 구체화 요청
   - 게임 장르 파악, 기획서 완성도 검토 요청
3. 구현 가능성 확인
   - 목숨바(체력바) UI 구현, 패링 기능, 아군 전환(반격) 시스템 등 구현 방법 확인
4. 기능 추가 요청
   - 목숨바(체력바) 를 하트에서 세로 바 형태로 변경
   - 1초마다 체력 감소 기능 추가
   - 스페이스바 패링 기능 추가 (원형 충돌 범위)
   - 패링 성공 시 체력 회복 및 적을 아군으로 전환하는 기능(반격) 추가

## AI 답변에서 도움이 된 것
- 코드를 구간별로 명확하게 설명해줘서 템플릿의 구조를 파악할 수 있었음
- 목숨바(체력바)의 위치 및 크기 계산 코드를 짚어주어 직접 수정이 가능했음
- 패링, 아군 전환 등 새로운 기능의 코드를 작성해주어 쉽게 템플릿의 수정이 가능했음
- 오류 발생 시 원인을 물어 빠른 시간에 오류를 해결할 수 있었음

## AI 답변을 수정하거나 버린 것
- 피격 시 모든 적이 사라지는 기능의 위치를 물어보고, 일단 주석 처리하여 코드가 작동하지 않게 해둠
- 패링 원형 충돌 반지름, 유지 시간 등 수치는 AI 제안값을 기반으로 직접 조정했음
- AI가 제시한 UI의 위치를 수정하여 플레이어 관련 UI가 오른쪽에 위치하도록 조정했음
